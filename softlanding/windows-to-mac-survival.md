# 윈도우 사용자 → 맥 생존 가이드

> bootstrap.sh 가 깔아준 것들로 **무엇을 어떻게** 쓰는지. 윈도우에서 당연했던 것들 중 맥에서 가장 헷갈리는 12가지를 정리한다.

---

## 0. 가장 먼저 알아둘 단어

| 윈도우 | 맥 | 비고 |
|---|---|---|
| Ctrl | ⌘ Command | 복사/붙여넣기/저장 등 90% 동일 |
| Alt | ⌥ Option | 숨은 메뉴, 복사↔이동 토글, 특수문자 |
| Win | ⌃ Control + ⌘ + ⌥ | "Hyper Key" 로 묶어서 쓰는 게 표준 (Karabiner-Elements) |
| Esc | ⎋ Esc | 동일 |
| Enter | ↩ Return | 거의 동일 (한글 기준 "엔터") |
| Print Screen | ⌘⇧3 / ⌘⇧4 / ⌘⇧5 | 4 = 영역, 5 = 녹화 |
| Backspace | ⌫ Delete | 맥은 Delete 라고 부름 |
| Delete (앞쪽 삭제) | ⌃D 또는 Fn + ⌫ | 맥에는 별도 키 없음 |
| Win+E (탐색기) | ⌘N (Finder 새 창) | Finder = 탐색기 |
| Win+L (잠금) | ⌃⌘Q | 즉시 잠금 |
| Alt+F4 | ⌘Q | 앱 종료. ⌘W 는 창만 닫음 |
| Alt+Tab | ⌘Tab + **AltTab 앱** | 기본 ⌘Tab 은 "앱 단위". **창 단위**로 바꾸려면 AltTab |
| Win+화살표 (스냅) | Rectangle 단축키 | bootstrap 으로 깔림 |
| Win+V (클립보드 히스토리) | Maccy 단축키 | bootstrap 으로 깔림 |

---

## 1. 창 닫기 ≠ 앱 종료 (가장 큰 함정)

윈도우에서는 빨간 X 누르면 앱이 죽지만 **맥은 창만 닫고 앱은 살아 있음**. 메뉴바에 점이 남아 있음.

- **앱 완전 종료: `⌘Q`**
- 종료해야 권한 변경/업데이트가 반영되는 경우가 매우 많음 (WinMacKey, Karabiner 등)
- 강제 종료: `⌘⌥⎋` 또는 `⌘⌥⇧⎋` 길게 (최전면 앱 강제 종료)

---

## 2. Alt+Tab 이 이상하다 → AltTab 앱

- 기본 ⌘Tab 은 **앱 단위** 만 보여줌. 같은 앱의 여러 창은 안 보임.
- bootstrap 으로 깔린 **AltTab** 앱이 이걸 해결:
  - 최초 실행 후 **시스템 설정 → 손쉬운 사용 → AltTab 권한 ON** + 재실행
  - 기본 단축키는 `⌥Tab` (윈도우 Alt+Tab 그대로)
  - 설정에서 `⌘Tab` 가로채기로 바꿔도 됨

---

## 3. 스크롤 방향이 거꾸로 → bootstrap 이 윈도우식으로 바꿔둠

- 맥 기본은 "자연 스크롤" — 휠 위로 = 페이지 아래로 (휴대폰처럼)
- bootstrap.sh 는 기본으로 **윈도우식 (자연 스크롤 OFF)** 로 적용
- 원복: `NATURAL_SCROLL=1 bash bootstrap.sh`
- 시스템 설정 → 트랙패드 → 스크롤 및 확대/축소 → "자연스러운 스크롤" 토글

### 외부 마우스 (특히 로지텍): Mos
- 맥 기본은 외부 마우스 스크롤이 뚝뚝 끊김. **Mos** 가 부드럽게 만들어줌
- Mos 메뉴바 아이콘 → 설정 → 외부 마우스 스크롤 방향 **반전 ON** (이게 윈도우식)
- 트랙패드와 외부 마우스를 **다른 방향**으로 두는 게 핵심

### Logi Options+ (로지텍 마우스/키보드 전용)
- MX Master, MX Keys 등 로지텍 제품의 **버튼 매핑, 제스처, 앱별 프로파일**
- 처음 연결 시 권한 허용 + 펌웨어 업데이트 권장
- "Smart Actions" 로 ⌘+Tab, Mission Control 등을 사이드 버튼에 매핑 가능

---

## 4. 한영 전환

- 기본: `⌃Space` (Control + Space) — 입력 소스 전환
- 또는 `⇪ Caps Lock` 한 번 짧게 누르기
- 잘 안 먹으면 시스템 설정 → 키보드 → 입력 소스 → "한국어 - 2벌식" 추가됐는지 확인
- 한자/특수문자: `⌥⌃Space` (이모지/심볼 패널)

---

## 5. 스크린샷 (윈도우 캡처 도구보다 강함)

| 단축키 | 동작 |
|---|---|
| `⌘⇧3` | 전체 화면 |
| `⌘⇧4` | 영역 선택 |
| `⌘⇧4` 후 `Space` | 창 단위 (그림자 포함) |
| `⌘⇧5` | 화면 녹화 + 옵션 패널 |
| `⌘⇧6` | Touch Bar 캡처 (있을 때) |

- bootstrap 으로 적용된 기본값:
  - **저장 위치**: `~/Downloads`
  - **형식**: PNG
  - **창 그림자**: 제거 (붙여넣기 깔끔)
  - **파일명에 날짜**: 포함

---

## 6. 절전 방지 — Amphetamine

- 윈도우의 PowerToys Awake 와 동일
- bootstrap (mas) 으로 자동 설치됨
- 메뉴바 ☕ 아이콘 → "Start New Session" → 시간/조건 선택
- "이 앱이 켜져 있는 동안", "특정 프로세스 실행 중", "다운로드 끝날 때까지" 등 트리거 풍부
- 자주 쓰는 케이스: 발표, 긴 빌드/다운로드, 외부 모니터 작업

---

## 7. 배터리 / 절전 설정

bootstrap 이 다음을 적용 (AC 어댑터 기준):
- 디스플레이 sleep: 30분
- 시스템 sleep: 0 (안 잠)

추가로 시스템 설정에서 확인할 것:
- **배터리 → 배터리 상태**: 충전 횟수, 최대 용량 (95% 이상이면 양호)
- **배터리 → 옵션 → 약간의 배터리 사용량...** : 배터리 사용 시 자동 절전
- **제어 센터 → 배터리 → 메뉴바에 표시 + 비율 표시**: 메뉴바에 % 띄우기 (Sonoma+ 는 GUI 토글)

---

## 8. 다크모드

- bootstrap 이 기본으로 **다크모드 ON** 적용 (눈 편함, 개발자 표준)
- 원복: `DARK_MODE=0 bash bootstrap.sh`
- 또는 시스템 설정 → 모양 → 라이트/다크/자동
- "자동" 으로 두면 일출/일몰 따라 자동 전환

---

## 9. 키보드 — Hyper Key 와 리더키 (선택, 고급)

**Karabiner-Elements** 가 bootstrap 으로 깔림. 표준 매핑 추천:

### CapsLock → Hyper Key (⌘⌥⌃⇧)
- CapsLock 을 거의 안 쓰니까 4개 modifier 의 합으로 매핑
- 예: `Hyper + R` → Raycast, `Hyper + T` → Ghostty, `Hyper + S` → Slack
- 단축키 충돌 0 (어떤 앱도 ⌘⌥⌃⇧ 조합은 안 씀)

### 리더키 (Leader Key) 패턴
- Vim 의 leader 처럼 "특정 키 누르고 다음 키" 로 명령
- Karabiner 의 "Complex modifications" 로 구현 가능
- 권장 시작 매핑: `Right ⌘` 을 leader 로 → 다음 키에 따라 액션 분기
- 처음에는 Raycast Hotkeys + AltTab + Rectangle 만으로도 충분. Karabiner 는 익숙해진 다음에.

### 키 반복 빠르게 (이미 bootstrap 으로 적용)
- 윈도우보다 맥 기본이 답답함. bootstrap 이 가장 빠른 값으로 설정:
  - `KeyRepeat=2` (가장 빠름)
  - `InitialKeyRepeat=15` (가장 짧은 대기)

---

## 10. 클립보드 히스토리 — Maccy

- 윈도우 Win+V 대체
- bootstrap 으로 깔림
- 최초 실행 시 **시스템 설정 → 손쉬운 사용 → Maccy 권한 ON**
- 기본 단축키: `⌘⇧C` — 최근 복사 100개 패널
- 검색 가능, 핀 기능, 코드/이미지 모두 보관

---

## 11. 파일 자르기 / 붙여넣기

- 맥의 Finder 는 **자르기 단축키가 없음**. 대신:
  - 일반 복사: `⌘C`
  - 붙여넣을 때 **자르기처럼 이동**: `⌘⌥V`
- 드래그도 동일: 드래그하면 복사, **드래그 + ⌘** 누르면 이동

---

## 12. 메뉴바 정리 — Hidden Bar

- 메뉴바 아이콘이 너무 많아지면 노트북 화면에서 안 보임
- bootstrap (mas) 으로 자동 설치됨
- 화살표 클릭으로 자주 안 쓰는 아이콘들 숨김
- ⌘ 누르고 드래그하면 메뉴바 아이콘 순서 변경 가능

---

## 부록 B. 자주 묻는 질문

**Q. 단축키가 어떤 앱은 되고 어떤 앱은 안 된다.**  
A. 권한 문제 99%. 시스템 설정 → 개인정보 보호 및 보안 → 접근성/입력 모니터링 확인. 권한 ON 후 **앱 완전 종료(⌘Q) → 재실행**.

**Q. 외부 모니터에서 화면이 흐릿하다.**  
A. 시스템 설정 → 디스플레이 → 해당 모니터 → "더 많은 공간" 또는 "원래 해상도" 선택. 4K 모니터에 HiDPI 가 안 잡혔을 가능성. BetterDisplay 라는 무료 앱이 표준 해결책 (이 가이드 범위 밖).

**Q. 파일 미리보기가 윈도우보다 느리다.**  
A. 그냥 `Space` (Quick Look) 가 윈도우보다 훨씬 빠름. 파일 선택 후 Space.

**Q. 한 번에 두 창 띄우기?**  
A. Rectangle 단축키 ( `⌃⌥←`, `⌃⌥→` ). Windows 의 Win+화살표와 동일.

**Q. "여러 앱 한꺼번에 보기" (윈도우의 작업 보기)?**  
A. F3 또는 트랙패드 4손가락 위로 (Mission Control).
